## Deutsch

**R3Ds CanonScan 0.5.0** unterstützt die Hardware-Starttaste des **Canon imageFORMULA P-208II**.

- Bei leerem Dokument startet die Taste einen Scan. Bei einem offenen Dokument fügt sie weitere Seiten hinzu – mit den aktuellen Scanoptionen.
- Die Taste ist aktiv, solange das Dokumentfenster im Vordergrund ist. „Scannertaste bereit“ zeigt die Bereitschaft an. Unter „Scanoptionen“ lässt sich „Scannertaste verwenden“ abschalten.
- Während anderer Vorgänge und Dialoge pausiert die Tastenabfrage. Der Scanner wird vor dem Einlesen freigegeben; ein bereits gehaltener Tastendruck löst keinen erneuten Scan aus.

Scanstart über die Taste und das Hinzufügen weiterer Seiten zu einem offenen Dokument wurden am P-208II vom Nutzer bestätigt. Diese Bestätigung gilt für die lokale Testversion; das veröffentlichte Releaseartefakt wurde nicht separat an Hardware geprüft.

Für **Apple Silicon ab macOS 27**. Die **macOS-arm64.zip** laden und die App nach „Programme“ ziehen. Am Scanner Auto Start ausschalten. Kein Canon-Treiber und keine Homebrew-Installation nötig. Die zusätzlichen Backendquellen enthalten den Tastenhelfer und die Buildanleitung.

## English

**R3Ds CanonScan 0.5.0** supports the **Canon imageFORMULA P-208II hardware Start button**.

- With an empty document, the button starts a scan. With an existing document, it appends more pages using the current scan settings.
- The button is active while the document window is in the foreground. “Scannertaste bereit” indicates readiness. Disable “Scannertaste verwenden” in scan options if needed.
- Button listening pauses during other operations and dialogs. The listener releases the scanner before acquisition; an already held button does not trigger another scan.

The user confirmed both starting a scan with the button and appending pages to an existing document on the P-208II. This confirmation applies to the local test build; the published release artifact has not undergone a separate hardware test.

For **Apple Silicon, macOS 27+**. Download **macOS-arm64.zip** and move the app to Applications. Turn the scanner's Auto Start switch off. No Canon driver or Homebrew runtime is needed. The separate backend source archive includes the button helper and build instructions.
