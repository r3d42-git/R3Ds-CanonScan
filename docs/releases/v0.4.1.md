## Deutsch

Fehlerbehebung für **R3Ds CanonScan** auf **Apple Silicon ab macOS 27** mit dem **Canon imageFORMULA P-208II per USB**.

- Fehlende PNG-Unterstützung im Scannerhelfer behoben: Die Buildkonfiguration berücksichtigt jetzt die zlib-Abhängigkeit der statischen libpng.
- PNG-Unterstützung wird beim Wiederverwenden des Buildcaches und am fertigen Releaseartefakt geprüft.
- Die Fehlermeldung bei fehlender PNG-Unterstützung wurde korrigiert; sie meldet keine vermeintlich vom Gerät nicht unterstützte Scanfunktion mehr.

Ein erfolgreicher Scan am Dock wurde am 14.11.2026 mit dem korrigierten, lokal installierten Build vom Nutzer bestätigt. Diese Bestätigung bezieht sich auf diesen lokalen Build; das neue Releaseartefakt wurde damit nicht separat an Hardware geprüft.

Zum Benutzen die **macOS-arm64.zip** laden und die App nach „Programme“ ziehen. Kein Canon-Treiber und keine Homebrew-Installation nötig. Am Scanner Auto Start ausschalten. Die zusätzlichen Backendquellen enthalten die Buildanleitung.

## English

Bug fix for **R3Ds CanonScan** on **Apple Silicon, macOS 27+**, with the **Canon imageFORMULA P-208II over USB**.

- Restored PNG support in the scanner helper by including static libpng's zlib dependency in the build configuration.
- Added PNG capability checks when reusing the build cache and when verifying the final release artifact.
- Corrected the error message for missing PNG support so it no longer suggests that the scanner does not support the requested function.

On November 14, 2026, the user confirmed a successful scan through the dock with the corrected, locally installed build. This confirmation applies to that local build; it does not constitute a separate hardware test of the new release artifact.

Download **macOS-arm64.zip** and move the app to Applications. No Canon driver or Homebrew runtime is needed. Turn the scanner's Auto Start switch off. The separate backend source archive includes build instructions.
